# HR-Employee-Attrition-Analysis

## Data Dictionary

| Column           | Description                      | Type         |
| ---------------- | -------------------------------- | ------------ |
| Employee ID      | Unique employee identifier       | Text         |
| Age              | Employee age                     | Whole number |
| Department       | Employee department              | Text         |
| Job Role         | Employee role                    | Text         |
| Salary 2023      | Employee salary in 2023          | Decimal      |
| Overtime         | Whether employee worked overtime | Category     |
| Job Satisfaction | Employee job satisfaction score  | Numeric      |
| Attrition Status | Whether employee left            | Category     |
